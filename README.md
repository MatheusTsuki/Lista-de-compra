# Lista-de-compra

O projeto esse projeto foi desenvolvido usando HMTL, CSS e Javascript, o sistema tem como função adicionar, editar e excluir os produtos que você colocar na lista, marcar intes como comprados e calcula eles automaticamente o valor de suas compras. Também utiliza LocalStorage para salvar os produtos no navegador, mantendo as informações mesmo após atualizar a página. O objetivo do projeto é praticar lógica de programação, manipulação do DOM e desenvolvimento web.
